# Device library: sources and licenses

`devices.json` holds real desktop Firefox device records (navigator, screen, WebGL
vendor/renderer) in Camoufox's fingerprint-preset shape, plus an `id` and a `source`
per record. It is generated by `scripts/build_device_library.py`; do not edit by hand.

## Filtering

Every record from every source must pass, in this order:

1. Desktop, screen at least 1280x720; macOS also at least 1280x800 (no Mac has a smaller
   logical screen); `maxTouchPoints` 0 on macOS, 0 to 10 elsewhere.
2. WebGL (vendor, renderer) is in `camoufox.webgl.firefox_gpus(os)` (the only GPUs with
   recorded WebGL parameters), fits the OS (`camoufox.coherence.gpu_fits_os`), and is
   neither `Mozilla` nor a software renderer (`camoufox.fingerprints.is_software_renderer`).
   Apify renderers are already Firefox's sanitized buckets ("... , or similar"), so they
   are used verbatim.
3. `camoufox.utils.launch_options(..., fingerprint_preset=record)` must not raise, must keep
   the record's GPU and screen size (Camoufox's own repairs mean the device is incoherent),
   and the decoded config must pass `camoufox.coherence.validate`,
   `gpu_screen_is_plausible`. Core count is judged as recorded, not as the build host's.
4. Records missing a required field (older presets without `devicePixelRatio`) are dropped.
5. De-duplicated on (os, UA OS part, platform, cores, screen WxH, dpr, GPU); earlier sources win.
